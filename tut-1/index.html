First Animation

  • repeat: -1; is used to perform infinite animation
  • yoyo: true; is used to move the item back to its original position after animation has ended (used if repeat != 0 as this back and forth movement will only be display if repeat is set to value other than 0)
  • onComplete is the function that is performed when the animation has been completed
  • x:val, y:val is used to move the object back(-ve x), forth(+ve x) and top(-ve y) and bottom(+ve y)
  • Scale is used to transform the size of the object if scale>1 object size increases and if scale<1 object size decreases)
